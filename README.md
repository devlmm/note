### 🎯 为什么会有这个仓库？

作为一名技术学习者，我深知：

* 知识点零散 → 需要系统整理
* 看完就忘 → 需要可复用的笔记
* 想记笔记又没时间排版 → 需要优雅的写作与阅读环境

因此，我创建了这套 **GitBook + GitHub 双端同步的知识库**：

* **GitBook 端**：提供目录、搜索、高亮、阅读进度等**极致阅读体验**
* **GitHub 端**：提供版本控制、Issue 讨论、PR 协作、**开源共享**

> 👉 **推荐你先去 GitBook 快速浏览**：[点我进入在线笔记](./) 喜欢的话，别忘了回来点个 ⭐ Star 支持一下\~

### 🚀 你可以怎么用这套笔记？

#### 1️⃣ 纯阅读（推荐方式）

* **在线 GitBook**：访问 [GitBook](./) ，获得最佳阅读体验
* **GitHub 直接看**：进入 `docs/` 目录，每个 `.md` 文件即是一个章节

#### 2️⃣ 下载 / 离线阅读

```bash
git clone https://github.com/devlmm/note
# 然后使用你喜欢的 Markdown 编辑器打开（如 Typora、VS Code）
```
